# Choosing a licence

No licence has been selected automatically for LUNA. Publishing source on GitHub does **not** by itself grant others permission to copy, modify or redistribute it.

Before accepting contributions or describing the project as open source, choose a licence that matches your goals:

- **MIT:** Simple permissive licence; permits reuse with copyright and licence notice.
- **Apache-2.0:** Permissive, with more explicit patent terms.
- **GPL-3.0:** Copyleft licence; redistributed derivatives must comply with its terms.
- **No licence:** Publicly visible source, but no general reuse permission. Less suitable for an open-source community project.

If you choose MIT, use GitHub's licence picker or the official template and replace the copyright line with the correct copyright holder and year. **Do not add a licence claiming ownership of third-party code.**

LUNA uses independent application code and a documented protocol derived from interoperability analysis. The original proprietary Android APK and decompiled source are intentionally excluded. Libraries such as PySide6, Bleak, NumPy, sounddevice, Android SDK and Gradle retain their own licences; review their terms, especially if distributing binaries.

The icon and other artwork should only be published if you have the right to distribute them. The bundled LUNA icon is included here as part of the project assets, but its origin and redistribution rights should be confirmed by the project owner before public release.
